# Spruco#5 — credits

A love letter to [spruceOS](https://github.com/spruceUI/spruceOS) by spruceUI.
Its look follows spruceOS's default SPRUCE theme (by tenlevels): the colors,
the 1×4 icon menu, the orange-edged selection, the yellow button hints and the
page counter are all taken from how spruce draws its own UI. spruce, spruceOS
and the spruce tree are spruceUI's; this theme isn't an official spruceUI
project.

Apart from the spruce tree (below), no spruce files are included: the spruce
theme's other images were only looked at for their colors and layout, and
everything else here was made fresh for Songo.

## The spruce tree
`assets/spruce_tree.png`, the tree in the top bar, is spruceOS's own: the
last frame of its loading animation (`Themes/SPRUCE/skin_1024x768/app_loading_05.png`),
cropped to the tree. As spruceOS's license asks:

## Icons
The icons in `assets/icons/` (menu, player and status icons) were drawn for
this theme as SVGs, in the outlined, round-capped style of the
Icons8 Forma set that spruce uses. Plugin menu entries keep their own icons.

## Everything else
The battery, wifi mark, button hints, progress bar and visualizer are drawn
in code (`assets/*.gd`). `preview.png` is a screenshot of the theme running.

Theme by Claude (Anthropic), made for Songo#5.
